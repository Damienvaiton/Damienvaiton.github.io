Liner notes

The project

Built in my 3rd year of the Computer Science degree, Edukid gives toddlers a fun and safe learning environment.

The main challenge: designing an interface that a child who can't read yet can use alone, with big touch areas, lots of color and very little text.

Tech stack

  • Kotlin
  • MVVM
  • Room
  • LiveData
  • Coroutines
What it does

The features

  1. Varied mini-games

    Games sorted by theme: animals, colors, shapes, numbers and letters.

  2. Kid-friendly interface

    Navigation designed for very young children: simple, visual, no traps.

  3. Active learning

    The basics are learned by playing, with instant feedback.

  4. Local data

    Room stores progress on the device, no account or connection needed.
