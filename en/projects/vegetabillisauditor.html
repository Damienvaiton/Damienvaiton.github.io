Track 03

Vegetabillis Auditor

From Arduino sensors to your phone: real-time monitoring of biology experiments.

Code on GitHub
Context
School project, 2nd year
Client
IUT biology department
Platform
Arduino + Android
Liner notes

The project

A project for the biology department of the IUT in Bourg-en-Bresse, which needed to monitor experiments without staying glued to the instruments.

An Arduino board reads the sensors and sends the measurements to the cloud, and an Android app displays them live for teachers and students.

Tech stack

  • Java
  • Arduino
  • Firebase
  • MVVM
  • IoT
What it does

The features

  1. IoT data capture

    Real-time O₂, CO₂ and light measurements from an Arduino board.

  2. Cloud storage

    Measurements sync instantly to Firebase and can be checked remotely.

  3. Live charts

    Curves displayed on Android, from the lab or anywhere else.

  4. Administration

    Manage the collected data from the mobile interface.
