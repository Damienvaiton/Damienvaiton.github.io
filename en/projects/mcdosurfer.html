Liner notes

The project

This game was made during the 3rd-year Unity course of the Computer Science degree. The goal: master the engine's fundamentals by building a complete game.

The runner: a genre that's easy to pick up, but that forces you to handle physics, collisions, level generation and scoring.

Tech stack

  • Unity
  • C#
  • Game design
What it does

The features

  1. Runner

    Gameplay inspired by classics like Subway Surfers: run and dodge.

  2. Endless mode

    As long as the player avoids obstacles, the run keeps going.

  3. Collectibles

    A score system based on items picked up during the run.

  4. Physics and obstacles

    Collisions and character reactions to the environment.
