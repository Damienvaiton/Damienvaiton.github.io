Liner notes

The project

A personal project born on a Discord server among friends: automate the welcome of new members and add a bit of fun.

The bot runs on Node.js: Discord.js handles the Discord API, and Axios fetches external data for the quizzes.

Tech stack

  • JavaScript
  • Node.js
  • Discord.js
  • Axios

This bot is no longer maintained: I moved on to a more ambitious Discord bot, Kitty.

What it does

The features

  1. Member management

    Automatically assigns a role as soon as a new user joins the server.

  2. Quizzes

    Interactive games, like a flag quiz, to liven up the community.

  3. Discord API

    Discord.js to talk to the Discord API simply and efficiently.

  4. Engagement

    Commands around the shared interests of the server's members.
