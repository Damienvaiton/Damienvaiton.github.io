Piste 03

Vegetabillis Auditor

Des capteurs Arduino jusqu'au smartphone : le suivi en temps réel d'expériences de biologie.

Code sur GitHub
Contexte
Projet BUT, 2e année
Client
Département biologie de l'IUT
Plateforme
Arduino + Android
Notes de pochette

Le projet

Un projet mené pour le département biologie de l'IUT de Bourg-en-Bresse, qui avait besoin de suivre des expériences sans rester collé aux instruments.

Une carte Arduino relève les capteurs, envoie les mesures dans le cloud, et une app Android les affiche en direct pour les enseignants et les étudiants.

Stack technique

  • Java
  • Arduino
  • Firebase
  • MVVM
  • IoT
Ce qu'il fait

Les fonctionnalités

  1. Acquisition IoT

    Mesures en temps réel d'O₂, de CO₂ et de luminosité via une carte Arduino.

  2. Stockage cloud

    Synchronisation immédiate des mesures dans Firebase, consultables à distance.

  3. Graphiques en direct

    Visualisation des courbes sur Android, directement depuis la salle de TP ou ailleurs.

  4. Administration

    Gestion des données collectées depuis l'interface mobile.
