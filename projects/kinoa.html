Notes de pochette

Le projet

Un projet perso né sur un serveur Discord entre amis : automatiser l'accueil des nouveaux membres et ajouter un peu de jeu.

Le bot tourne sous Node.js : Discord.js gère le dialogue avec l'API Discord, Axios récupère les données externes des quiz.

Stack technique

  • JavaScript
  • Node.js
  • Discord.js
  • Axios

Ce bot n'est plus maintenu : je suis passé à un bot Discord plus ambitieux, Kitty.

Ce qu'il fait

Les fonctionnalités

  1. Gestion des membres

    Attribution automatique d'un rôle dès qu'un nouvel utilisateur arrive sur le serveur.

  2. Quiz

    Des jeux interactifs, comme un quiz sur les drapeaux, pour animer la communauté.

  3. API Discord

    Discord.js pour dialoguer simplement et efficacement avec l'API Discord.

  4. Animation

    Des commandes autour des centres d'intérêt communs des membres du serveur.
